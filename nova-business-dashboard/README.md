# Nova — Premium Business Intelligence Dashboard

A unique, responsive business dashboard built with **HTML5, Tailwind CSS and vanilla JavaScript**.

## Features
- Responsive desktop, tablet and mobile layout
- Premium glassmorphism + mesh-gradient visual system
- Light/dark mode with localStorage persistence
- Interactive sidebar navigation
- Revenue and pipeline dashboard
- Transaction table and weekly focus panel
- Search modal with Cmd/Ctrl + K shortcut
- Export report action
- Mobile navigation drawer
- No framework or build step required

## Run locally
Open `index.html` in a browser. Tailwind is loaded through the official CDN, so no installation is required.
